## 📋 Обзор проекта

MODOCRM — это полнофункциональная система управления взаимоотношениями с клиентами (CRM), специально разработанная для компаний, занимающихся производством и установкой окон, дверей и других столярных изделий.

### 🎯 Ключевые возможности

- **Управление клиентами**: физические лица и юридические лица (B2C и B2B)
- **Система предложений**: создание коммерческих предложений с продуктовым конфигуратором
- **Продуктовый конфигуратор**: визуальная настройка параметров окон и дверей
- **Управление контрагентами**: поставщики, партнёры, установщики
- **Гибкая система параметров**: категории, параметры, значения с поддержкой переопределений
- **Многоязычность**: полная поддержка русского и итальянского языков
- **Печать документов**: генерация PDF с коммерческими предложениями

## 💾 База данных

### Основные модели

#### Клиенты (Client)

```prisma
model Client {
  id            String
  type          ClientType  // individual | company
  firstName     String?
  lastName      String?
  companyName   String?
  phone         String?
  email         String?
  address       String?
  codiceFiscale String?
  partitaIVA    String?
  source        String?
  notes         String?
  proposals     Proposal[]
}
```

#### Предложения (Proposal)

```prisma
model Proposal {
  id                String
  proposalNumber    String
  client            Client
  items             ProposalItem[]
  subtotal          Float
  vatTotal          Float
  total             Float
  status            String
  validUntil        DateTime?
  notes             String?
}
```

#### Продукты (ProposalItem)

```prisma
model ProposalItem {
  id             String
  proposal       Proposal
  category       ProductCategory
  supplier       Supplier
  parameters     Json  // { parameterId: value }
  quantity       Int
  unitPrice      Float
  vatRate        Float
  total          Float
}
```

#### Параметры (ParameterTemplate)

```prisma
model ParameterTemplate {
  id          String
  name        String
  nameIt      String?
  type        ParameterType  // TEXT | NUMBER | COLOR | SELECT | BOOLEAN
  description String?
  unit        String?  // mm, см, м
  minValue    Float?
  maxValue    Float?
  step        Float?
  isGlobal    Boolean
  isActive    Boolean
  values      ParameterValue[]
}
```

#### Значения параметров (ParameterValue)

```prisma
model ParameterValue {
  id             String
  parameter      ParameterTemplate
  value          String
  valueIt        String?
  hexColor       String?  // для COLOR
  ralCode        String?  // автоматически из HEX
  approvalStatus String  // approved | pending
  isActive       Boolean
  order          Int
}
```

### 2. Коммерческие предложения

**Создание предложения:**

1. **Системная информация**: дата, менеджер, статус, срок действия
2. **Выбор клиента**: поиск или создание нового
3. **Добавление продуктов**: через продуктовый конфигуратор
4. **Расчёт итогов**: с НДС, скидками

**Функции:**

- Автоматическая нумерация (PROP-XXX)
- Статусы: черновик, отправлено, одобрено
- Массовое применение НДС к позициям
- Генерация PDF с логотипом компании
- Визуализация продукта в предложении

### 3. Продуктовый конфигуратор

**Трёхшаговый процесс:**

#### Шаг 1: Выбор категории

- Визуальный выбор с иконками (Двери, Окна, и т.д.)

#### Шаг 2: Выбор поставщика

- Фильтрация по категории
- Отображение привязанных поставщиков

#### Шаг 3: Настройка параметров

- Динамическая загрузка параметров категории
- Применение переопределений поставщика
- Группировка параметров (Размеры, Материалы, Функциональность)
- Inline добавление новых значений параметров
- Модальное окно управления значениями

**Визуализация:**

- Фиксированный размер (300x400px)
- Динамические линии размеров (width, height)
- Отображение цвета рамы (из параметра)
- Стрелки направления открытия
- Индикация типа открытия

### 4. Система параметров

**Уровни параметров:**

1. **Глобальные параметры**: применимы ко всем категориям
2. **Параметры категории**: специфичные для категории (двери, окна)

**Типы параметров:**

## 🎨 HEX → RAL конвертация

**Уникальная функция:** автоматическая конвертация HEX цветов в ближайший RAL код!

### Как работает:

1. Пользователь выбирает цвет в color picker
2. Система конвертирует HEX в RGB
3. Рассчитывается Евклидово расстояние до всех RAL цветов
4. Определяется ближайший RAL код
5. Автоматически сохраняется в базу данных

### База данных RAL:

- 35+ популярных RAL цветов для окон и дверей
- Категории: белые, серые, коричневые, чёрные, цветные
- Примеры: RAL 9010 (Белый), RAL 7016 (Антрацит), RAL 8011 (Ореховый)

### Где используется:

- Inline добавление значений цвета
- Модальное окно управления значениями
- Таблица значений (колонка RAL)
- Визуализация продукта
